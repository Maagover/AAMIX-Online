# Repositorio de desarrollo AAMIX-Online

Base: AAMIX Online 1.3.1 (versión interna 1.11.1), copiada de la entrega local work/AAMIX_v1.11.1.

El código editable, los recursos y las pruebas están en proyecto/. Para editar, abrir proyecto/project.godot con Godot compatible (la entrega incluye Godot 4.7.2).

El motor de Windows se conserva en el ZIP completo de la entrega y no en el historial Git por su tamaño. La carpeta motor/ del paquete debe acompañar a AAMIX.exe para ejecutar la distribución portátil.

Este repositorio conserva una instantánea inicial; no reconstruye el historial anterior. Las publicaciones y actualizaciones del instalador existente siguen apuntando a Maagover/AAMIX.
